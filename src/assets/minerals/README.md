# Mineral tiles

Crystal images for the welcome step, one light and one dark SVG per tile.
Generated by `scripts/make_minerals.py` from the representative crystals of
Yiming Zhang's mineral-habit-matrix
(https://github.com/duserzym/mineral-habit-matrix, commit c744553, 2026-10-19;
live at https://duserzym.github.io/mineral-habit-matrix/), file
`site/data/atlas.json`. Titanite uses the envelope cell C2M3, carbonate is
calcite, and "other" is quartz in neutral grey.

    git clone --depth 1 https://github.com/duserzym/mineral-habit-matrix.git /tmp/mhm
    python3 -I scripts/make_minerals.py /tmp/mhm
